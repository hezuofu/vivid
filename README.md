# Vivid Framework

A Spring-like Java Web Framework

## Modules

- **vivid-core** - Core abstractions (HTTP, Handler, Filter, etc.)
- **vivid-beans** - IoC container and dependency injection
- **vivid-context** - Application context and resource handling
- **vivid-aop** - Aspect-oriented programming support
- **vivid-web** - Web core module
- **vivid-webmvc** - MVC annotation-driven
- **vivid-boot** - Auto-configuration and starters
- **vivid-jdbc** - JDBC abstraction
- **vivid-tx** - Transaction management
- **vivid-security** - Security framework

## Build

```bash
mvn clean install
```
